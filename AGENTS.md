# ceo

Build the portfolio coordinator, not a replacement coding worker. Keep Pi as a dependency and Orca as the execution backend. Role instructions belong in CompanyOS; do not copy gstack into this runtime.

Use native platform access. Preserve founder permissions, existing worker ownership, exact-artifact decisions and catalog pins. Store execution intent before side effects; reconcile uncertain outcomes before retry. Orca owns worker lifecycle. Never mark a worker successful from a transcript or a model claim.

This repository is public. Examples must be generic. Do not commit private configuration, traces, accounts, databases, credentials or reports. Team definitions are data, not executable extensions. Founder policy must not be editable through organization tools.

Run npm run check, npm test and npm run build. Tests use fixtures and fake model turns. Live smoke tests must have bounded scope, no product edits, no deployment, and retain native task/dispatch evidence.
